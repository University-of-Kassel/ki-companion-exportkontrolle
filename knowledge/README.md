# Fachliche Wissensbausteine

Stand: 22.10.2026 | Dokumentversion 1.1

Alle **36** Dateien in diesem Ordner sind institutionell neutralisierte Entwürfe mit `status: draft`. Sie werden ohne Freigabe für einen bestimmten institutionellen Einsatz veröffentlicht. Jede nachnutzende Einrichtung muss Inhalt, Quellenstand, institutionelle Passung und Einsatzbedingungen selbst prüfen.

Die beiden lokalen Vorlagen und KF-15 als Evaluationsmaterial liegen außerhalb dieses Ordners und stehen ebenfalls auf `draft`. Insgesamt enthält der Quellrelease 39 KF-Dateien mit identischem 13-Felder-Header.

Schema, Auswahl und lokale Freigaben sind in [Wissenspflege](../docs/knowledge-maintenance.md) beschrieben; die [Einrichtungsanleitung](../docs/setup.md) ist plattformneutral. Der mitgelieferte Paketbau verwendet ausschließlich `config/knowledge-manifest.json`. Bei einer eigenen Integration muss dieselbe kontrollierte Auswahl sichergestellt werden. Diese README wird nicht als Wissen mitimportiert.

`last_reviewed` bewahrt den bisher dokumentierten fachlichen Prüfstand; es ist weder eine Freigabe für die Nachnutzung noch das Datum der jüngsten technischen Aufbereitung. Der Draft-Status ist eine Kennzeichnung; fachliche Inhalte und Prüfdaten bleiben davon unberührt.
