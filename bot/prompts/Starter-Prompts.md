# Starter Prompts für den Forschendenbot

## Allgemeine Orientierung

```text
Erkläre mir folgenden Begriff kurz und mit einem Beispiel aus dem Hochschulkontext: [Begriff]
```

```text
Gib mir eine allgemeine Übersicht zu diesem Thema, ohne eine Einzelfallprüfung vorzunehmen: [Thema]
```

```text
Welche Rolle spielt Exportkontrolle oder Forschungssicherheit bei diesem Thema? [Thema]
```

## Schnellcheck für konkrete Vorhaben

```text
Führe mit mir einen kurzen Schnellcheck für eine neue internationale Forschungskooperation durch. Stelle mir jeweils höchstens drei Fragen.
```

```text
Ich möchte ein konkretes Vorhaben vorsichtig einordnen. Frage mich nur nach den Angaben, die für eine erste Orientierung wirklich entscheidend sind: [Vorhaben]
```

```text
Zerlege mein Vorhaben in einzelne Tätigkeiten und zeige mir, welche davon genauer betrachtet werden sollten: [Vorhaben]
```

## Daten, Software und Technologie

```text
Ich möchte Forschungsergebnisse, Daten, Software oder Quellcode mit externen Partnern teilen. Welche Informationen brauchst du für eine erste Orientierung?
```

```text
Wir möchten einer externen Person Remotezugriff auf Daten, Software oder IT-Systeme geben. Was sollte ich vorab klären?
```

```text
Welche weniger sensible Variante könnte ich für dieses Vorhaben wählen, ohne das Forschungsziel unnötig zu beeinträchtigen? [Vorhaben]
```

## Gastforschende und Zugänge

```text
Ich plane einen Gastaufenthalt oder möchte einer externen Person Zugang zu Laboren, Daten oder IT-Systemen geben. Was sollte ich vorbereiten?
```

```text
Welche Informationen sollte ich für die Prüfung eines Gastaufenthalts oder externen Zugangs zusammenstellen?
```

## Reisen, Versand und Mitnahme

```text
Ich reise zu einer Konferenz oder Forschungskooperation außerhalb der EU und nehme einen Laptop, Daten oder Geräte mit. Was sollte ich beachten?
```

```text
Ich möchte ein Gerät, Material oder eine Probe ins Ausland versenden. Welche Angaben sind für eine erste Orientierung wichtig?
```

## Laufende Projekte und Änderungen

```text
Was hat sich in meinem laufenden Projekt geändert und welche Punkte sollten deshalb neu betrachtet werden? [Änderungen]
```

```text
Wir haben einen neuen Partner, neue Zugriffsrechte oder ein zusätzliches Arbeitspaket. Welche Teile des Vorhabens sollten erneut betrachtet werden?
```

## Vorbereitung einer Anfrage

```text
Formuliere aus meinen Angaben eine datensparsame Anfrage an die zuständige Stelle: [Angaben]
```

```text
Strukturiere meinen Sachverhalt so, dass eine zuständige Fachstelle ihn möglichst schnell prüfen kann: [Angaben]
```

```text
Welche Angaben fehlen noch, bevor ich eine sinnvolle Anfrage an die zuständige Stelle senden kann? [Sachverhalt]
```
